# Copilot / Istruzioni operative (documento di progetto)

Queste sono le istruzioni operative per Copilot salvate nel repository come riferimento di progetto.

- Quando ricevi un task, modifica direttamente i file necessari senza limitarti a suggerire il codice.
- Se incontri un errore di linting, correggilo immediatamente.
- Opera in modalità autonoma.
- Al termine di ogni task, cerca sempre nuove feature da implementare su backend, frontend e mobile.
- Ottimizza e pulisci il codice, aggiungendo commenti dove utile.
- Rispondi sempre in italiano.
- Non eseguire mai test o build, limitati a modificare i file.
- Non chiedere mai un PR

---

Nota: questo documento è una copia del file `.github/workflows/copilot-instructions.md` e funge da linea guida interna al progetto. Le istruzioni di sistema esterne all'ambiente dell'assistente non possono essere modificate dal codice del repository; questo documento serve a fornire indicazioni operative al team.
